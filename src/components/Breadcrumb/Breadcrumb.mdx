# Breadcrumb

`Breadcrumb` 컴포넌트는 사용자의 현재 위치를 계층 구조로 보여주며 탐색을 돕습니다.

## React Wrapper 사용법

React 환경에서 `Breadcrumb` 컴포넌트를 import하여 사용합니다.

```tsx
import { Breadcrumb } from 'bizui-library';

const items = [
  { label: 'Home', href: '/' },
  { label: 'Library', href: '/library' },
  { label: 'Data' }
];

const App = () => (
  <Breadcrumb 
    items={items} 
    separator=">"
    onPathClick={(event) => console.log('Clicked:', event.detail.item)} 
  />
);
```
